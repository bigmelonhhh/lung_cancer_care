# 血糖详情测量场景展示条件设计

## 背景

患者端 `templates/web_patient/health_record_detail.html` 与医生移动端
`templates/web_doctor/mobile/health_record_detail.html` 当前会为所有血糖记录展示
“测量场景”。设备上传的血糖记录不应展示该信息。

## 目标行为

- 手动录入的血糖记录显示血糖值和测量场景。
- 设备上传的血糖记录仅显示血糖值，不显示测量场景。
- 患者端与医生移动端行为一致。
- 首屏服务端渲染记录与滚动加载记录行为一致。
- 其他健康档案类目及血糖值本身的展示不变。

## 实现设计

沿用记录数据中已有的 `record.is_manual` 标识，不调整后端查询、模型或接口结构。

在两个详情模板中分别收紧两条渲染路径：

1. Django 模板首屏渲染：仅当 `record.is_manual` 为真时渲染测量场景文本。
2. JavaScript 滚动加载渲染：仅当 `record.is_manual` 为真时拼接测量场景文本。

本次不移除设备记录返回数据中的 `measurement_context`，避免改变接口契约；展示规则由页面负责。

## 验证

- 患者端：验证手动血糖记录包含测量场景，设备血糖记录不包含对应场景文本。
- 医生移动端：验证手动血糖记录包含测量场景，设备血糖记录不包含对应场景文本。
- 运行两个受影响测试模块，确认现有图表和详情页行为未回归。
